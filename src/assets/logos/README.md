# Company logo slots

Drop a square logo here and it replaces the monogram on the matching
experience card.

| File name          | Experience card        | Suggested size        |
| ------------------ | ---------------------- | --------------------- |
| `cornerstone.png`  | Cornerstone OnDemand   | 256 × 256, transparent |
| `archover.png`     | Archover Solutions     | 256 × 256, transparent |

The `logo` field in each entry of `experience` (`src/data/profile.ts`) controls
the file name that is looked up.
